## 📌 Course Syllabus Overview

| Module | Module Name | Primary Technologies | Core Topics Covered |
| :---: | :--- | :---: | :--- |
| **01** | **Introduction to Web & WWW** | Web Architecture | Internet Protocols (HTTP/HTTPS), DNS, URL, Web Browsers, Cookies, Web Servers |
| **02** | **HTML & DHTML** | HTML5 | Structure, Headings, Text Formatting, Forms, Tables, Media Elements, Meta Tags |
| **03** | **Style Sheets (CSS)** | CSS3 | Selectors, Colors, Box Model, Text Formatting, Margins, Padding, Flexbox & Grid |
| **04** | **JavaScript & DOM** | ES6 / JS | Syntax, Variables, Functions, Arrays, Objects, DOM Manipulation, Event Listeners |
| **05** | **PHP & MySQL** | PHP & MySQL | Backend Logic, Form Handling, Sessions, Cookies, Database CRUD & Server Connection |
| **06** | **AJAX & JSON** | AJAX & JSON | Asynchronous Requests, XMLHttpRequest, Data Parsing, Dynamic DHTML updates |
